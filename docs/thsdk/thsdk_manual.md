## 1. 项目背景与目标

**目标**：复刻同花顺「决策先锋」功能（非仅接入数据），实现三大核心指标 + 共振选股：

- **GS 指标**（主图）：判断个股走势趋势
- **主力资金**（副图）：含主力明盘资金 + 主力暗盘资金，实时跟踪 5000+ 股票资金动向
- **AI 机构活跃度**（副图）：跟踪个股机构资金强度
- **共振选股**：三指标共振筛选强势个股

**技术底座**：通过 thsdk（v1.7.18）库接入同花顺行情服务器（TCP 直连，不依赖本地客户端），实测账号已开通云端版 Level-2 权限。

## 3. thsdk 登录方式（含账号密码）

### 3.1 登录方式总览

thsdk 仅支持以下三种登录方式，**无扫码登录**，与项目 `ths_auth` 扫码体系不互通（那是另一套 HTTP 认证，喂不了 thsdk）：

| 方式 | 说明 |
|---|---|
| 账号密码直登 | `THS({"username": ..., "password": ..., "mac": ""})` |
| 环境变量 | 设置 `THS_USERNAME` / `THS_PASSWORD` 后不传参 |
| 游客 | 不传账号，匿名访问（数据权限受限） |

### 3.2 实测账号凭据（本机专用，注意保密）

> 本手册包含敏感登录凭据，请勿外传、勿提交公开仓库；建议同时维护 `.env` 版本并加入 `.gitignore`。

- **用户名（THS_USERNAME）**：`<THS_USERNAME>(见 .env.sida.local / 不入 git)`
- **密码（THS_PASSWORD）**：`<THS_PASSWORD>(见 .env.sida.local / 不入 git)`
- 登录参数：`username + password + mac`（mac 可传空字符串）
- 账号类型：同花顺通行证账号（普通注册账号，非券商资金账号、非 iFinD 付费账号）
- **实测结果**：登录成功，可正常获取 search_symbols、klines 日K、market_data_cn 扩展1（主力净流入）、depth 五档盘口、wencai_nlp 问财选股等真实数据
- **L2 权限**：已开通**云端版 Level-2**（thsdk 走云端通道，需订阅电脑远航版/云端版 L2；手机版 L2 与云端版不互通）

### 3.3 登录代码示例

```python
import os
os.environ["PYTHONUTF8"] = "1"
from thsdk import THS

USERNAME = "<THS_USERNAME>(见 .env.sida.local / 不入 git)"
PASSWORD = "<THS_PASSWORD>(见 .env.sida.local / 不入 git)"

with THS({"username": USERNAME, "password": PASSWORD, "mac": ""}) as ths:
    # 在此调用各接口
    df = ths.klines("USZA002361", interval="day", count=100).df
    print(df.head())
```

## 5. 决策先锋三指标官方规格

> 依据：同花顺官方《决策先锋8问8答》PDF（10页）+ 公开拆解（CSDN），双向核对。

### 5.1 GS 指标（主图，判断走势）

- **G 信号**：趋势有望启动 → 实战文案 "GO: 趋势有望启动，建议逢低建仓"
- **S 信号**：趋势暂或结束 → 实战文案 "STOP: 趋势暂或结束，建议减仓避险"
- 关键细节：**非函数指标、出现后次日不消失**

### 5.2 主力资金（核心数据，实时跟踪 5000+ 股票）

**主力明盘资金**：单笔超过 **30 万**的大单资金（市场可见）；局限：可被拆单伪装，不能代表真主力。

**主力暗盘资金**：AI 大数据模拟运算得出的私募量化单、机构游资对倒拆单、大单拆小单资金；一定程度上代表机构、游资真正意图。

**显示口径（复刻关键）**：
- 明盘+暗盘净额 **> 0 = 流入（红）**；**< 0 = 流出（绿）**
- 支持 **1 / 3 / 5 日周期**
- 上穿/下穿 **0 轴** 定多空

**官方示例数据**：
- 中航产融：明盘 +1887.3 万 / 暗盘 +1052.8 万
- 欣锐科技：暗盘 -5116.7 万
- 杭州热电：暗盘 +1.33 亿 vs 明盘 -0.43 亿（暗盘与明盘方向相反时以暗盘为主）

### 5.3 AI 机构活跃度（副图，机构资金强度）

- **生命线 +1.56**：阈值线
- **强势线 +3.00**：站上 = 少数强势机构参与
- **大牛线 +6.00**：站上 = 短期多支强势机构参与
- 实现参考（公开拆解）：6 因子（影线/涨幅/高开等）取 MAX × 1.2
