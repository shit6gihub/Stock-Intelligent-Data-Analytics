## 二、8 个问答完整问题与核心答案要点

### 问题一：决策先锋软件是什么？

**答案要点**：
- 决策先锋是**同花顺推出的全新交易系统**，旨在利用**趋势、资金、活跃度的共振**，帮客户找出更好的买卖点。
- 实际使用中可以用软件看大盘、看板块、找买卖点，不同大盘行情下有不同战法。
- 产品构成：
  - **三大特色指标**：GS 策略、主力资金、AI 机构活跃度
  - **三大交易模型**：强势突破、顺势中继、趋势反转模型
  - **每日实战训练营**：交易系统理念课、交易模型战法课

### 问题二：什么是 GS 信号？

**答案要点**：
- GS 指标是**判断股票走势**的指标，是决策先锋工具的**特色指标**。
- 出现 **G 信号** = 趋势启动关注信号；结合资金情况与机构活跃度一起看，成功率会高些。**出现之后第二天不会消失（非函数指标）**。
- **G 信号**：趋势有望启动，注意机会挖掘。
- **S 信号**：趋势暂或结束，注意潜在风险。
- 功能详解链接：http://m.hexin.cn/_31412e

### 问题三：什么是主力资金？跟主力大单有什么区别？

**答案要点**：
- 主力资金是【决策先锋】**最核心的数据**，数据主要来源于**上交所和深交所**，能**实时跟踪五千多只股票**资金的动向。
- 主力资金分【主力明盘资金】与【主力暗盘资金】：
  - **主力明盘资金**：市场上大家都能看到的**单笔超过 30 万**的资金（大单资金）。**不能代表真正的主力**——主力机构可将大单拆小单、对倒拆单诱导散户；散户单笔超 30 万的资金也会被统计进主力大单。
  - **主力暗盘资金**：通过 **AI 大数据模拟、运算**得出的**私募量化单、机构游资对倒拆单、大单拆小单**的资金，是机构、游资的**真正意图**所在。
- 选股要点：必须选**主力暗盘资金持续流入**的股票，说明主力资金在底部吸筹。
- 功能详解链接：http://m.hexin.cn/_dudhio

### 问题四：什么是 AI 机构活跃度？

**答案要点**：
- **AI 机构活跃度**：跟踪个股**机构资金强度**，判断股票机构资金活跃强度；**活跃越强，可操作性越高**。
- **站上强势线**：表明个股有**少数强势机构**参与。
- **站上大牛线**：说明个股短期有**多支一线强势机构**参与操作。
- 关键线位（OCR 截图确认）：**生命线 +1.56、强势线 +3.00、大牛线 +6.00**。
- 示例规律：
  - 机构活跃度在**强势线下方**：股价震荡下行。
  - 机构活跃度持续在**强势线上方**：股价持续大涨。
  - **柱子越高，股价的振幅波动越大**。
- 功能详解链接：http://m.hexin.cn/_rx5bz5

### 问题五：自己平时参考主力大单资金和 MACD 比较多，决策先锋要看好几个指标么？

**答案要点**：
- 股票交易**多指标的共振**是提升交易成功率**最核心的要诀**。
- 需要**同时满足三大条件**：① 趋势（GS 信号）；② 资金（主力暗盘资金 + 主力明盘资金）；③ AI 机构活跃度。
- **【决策先锋三步战法】机会挖掘**：GS 策略出现 **G 信号** / AI 机构活跃度**强势线上方** / 主力资金**大笔买入**，三指标同时满足 → 注意机会挖掘。
- **【决策先锋三步战法】注意风险**：GS 策略提示 **S 信号** / 主力资金**流出** / 机构活跃度在**强势线下方**，三指标同时走坏 → 注意潜在风险。
- 实战示例：① 三指标共振 = G信号 + 资金流入 + 机构活跃度强势线（机会挖掘）；② 三指标走坏 = S信号 + 资金流出 + 机构活跃度生命线（潜在风险）。

### 3.2 主力资金（明盘 + 暗盘）

| 项目 | 官方描述 |
|---|---|
| 数据源 | 上交所、深交所；实时跟踪 5000+ 只股票资金动向 |
| **主力明盘资金** | 市场上大家都能看到的**单笔超过 30 万**的资金（大单资金）。不能代表真正主力：机构可拆小单/对倒拆单诱导散户；散户超 30 万单笔也计入 |
| **主力暗盘资金** | 通过 **AI 大数据模拟、运算**得出：私募量化单、机构游资对倒拆单、大单拆小单资金；代表机构/游资真正意图 |
| 判定规则 | **明盘和暗盘相加为正 → 主力资金流入**；其中**暗盘资金进出在一定程度上代表主力的"真正"想法** |
| 资金分层 | 主力机构（明盘=普通大单资金 / 暗盘=私募量化单、对倒拆单等）；散户（资金较多的散户 / 中小资金的散户） |
| 周期维度 | 支持 **1 日 / 3 日 / 5 日**（主力资金 1日3日5日），另有分时/日/周/月/年 |
| 【三日、五日主力资金】 | 判断资金**中期趋势**：红色=主力资金流入，绿色=主力资金流出；**由绿转红、上穿 0 轴 = 资金看多**；**由红转绿、下穿 0 轴 = 资金看空** |
| 示例-流入（中航产融 600705） | 主力资金3日：**+1545.02 万**，标注"上穿0轴，资金看多"；单日（2023/01/12，单位万元）：主力 **2940.1**、散户 -2940.1、明盘 **1887.3**、暗盘 **1052.8**（红柱） |
| 示例-流出（欣锐科技 300745） | 主力资金5日：**-7217.04 万**，标注"下穿0轴，资金利空"；单日（2023/02/16，单位万元）：主力 **-9674.1**、散户 9674.1、明盘 **-4557.4**、暗盘 **-5116.7**（绿柱） |
| 示例-暗盘主导（杭州热电 605011） | 单日（2023/05/23，单位亿元）：主力 **0.90**、散户 -0.90、明盘 **-0.43**、暗盘 **+1.33** → 明盘流出但暗盘大幅流入，仍呈主力流入 |
| 示例-明盘背离（2024/11/11 单位亿元） | 主力 **-1.05**、散户 1.05、明盘 **-3.84**、暗盘 **+2.79** → 明盘大幅流出、暗盘流入，印证"暗盘才是真正意图" |
| 衍生数据项 | 主力资金1日、主力暗盘资金1日、大单净量、大单金额、资金仓位 |

> **复刻要点**：明盘 ≈ 单笔 >= 30 万的大单资金（可直接从 L2 逐笔/分笔聚合）；暗盘 ≈ AI 模型对拆分单/对倒单的识别结果（需对逐笔订单做模式识别：大单拆小单、对倒、量化单特征）；主力资金净流入 = 明盘净额 + 暗盘净额；以 0 轴为多空分界，支持 1/3/5 日滚动聚合。

| 趋势 | 活跃度 | 主力资金 | 判断 | 操作思路 |
|---|---|---|---|---|
| G信号 | 强势线上 | 流入 | 三指标首次共振 | 注意机会挖掘 |
| G区间 | 强势线上（较前一日翻倍） | 流入（较前一日翻倍） | 三指标再次共振 | 持续关注机会 |
